# Billboard — Anonymous Message Board

Billboard is an anonymous message board on Aztec. Posters deposit ETH into an Ethereum portal to claim private posting rights, then publish messages without revealing their wallet address. Posting is rate-limited. Withdrawal requires collateral screening and a waiting period.

The deployer selects a moderator who publishes rules, flags posts, and can transfer their role. A moderation daemon runs a local language model to flag posts; flagged posts are hidden from the default feed and increase waiting periods.

Readers browse without a wallet; posters connect an Ethereum wallet which creates an Aztec account backed by passkeys. Private transaction fees are paid from Fee Juice-funded credit.

The application targets Aztec v5.2.0 and is not yet a production release.
