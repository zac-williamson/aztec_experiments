## Work

2. Reject normal unsolicited ETH; test forced ETH separately from credited collateral.
3. Implement recovery for this fresh deployment and document any supported deposit pause; preserve valid exits. Do not add legacy deployment or live-right migration. No refund may leave active L2 posting rights; state lost-secret and protocol-unavailability limits explicitly.
