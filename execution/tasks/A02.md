## Work

1. Use P04 toolchain-audit-classification.json and fresh publisher advisories to identify affected exact installed dependency paths and runtime reachability.
2. Apply compatible patched dependencies or supported replacements without silently mixing Aztec release artifacts or running unreviewed automatic fixes.
3. Qualify a patched Node24 runtime for its embedded networking library; update exact runtime pins, CI and build documentation together, with native/browser SDK compatibility and reproducibility checks. An npm override cannot patch Node itself.

5. Regenerate affected reproducible artifacts and rerun behavior/compatibility tests; bind the final lock and advisory inventory into the audit packet.
