## Work

1. Give every board a stable, shareable URL identifying its network and contract.
2. Load and verify public connection settings automatically; show messages on arrival without JSON import or an Open configured board step.
3. Keep operator connection settings out of the normal reader and poster journey; show clear loading, empty and failure states.

## Acceptance

- **U02-A01** — A fresh browser opens a board link and displays its messages without configuration or wallet connection.
- **U02-A02** — Reloading or sharing a link opens the same board; stale saved browser settings cannot silently select another board.
- **U02-A03** — The board and its messages appear first on desktop and mobile, with clear loading and error states.
