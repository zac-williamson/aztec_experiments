Constructor values use actual chain31337/version/address, positive bounded collateral/timing values, the fresh account as censor, and a short correctly packed UTF-8 policy. Deployment fixes the fresh account as deployer and uses a fresh salt.

Pinned5.2 DeployMethod has no `.prove` method. This module follows its actual request path and BaseWallet's send implementation through `completeFeeOptions`, `createTxExecutionRequestFromPayloadAndFee`, `pxe.proveTx` and `toTx`, stopping before submission. FeeJuice balance must be positive; no simulation fee bypass is supplied. It requires a nonempty genuine Chonk proof and calls `node.isValidTx(tx)` with default real-proof and fee-validation options. No send or included receipt is fabricated. Crucially, the board initializer itself is public: this first client proof authenticates the private account/transaction path, while execution and proving of that public initialization require later inclusion/server proof.

Native private-kernel settings belong in `pxe.proverOrOptions`, with BackendType.NativeUnixSocket, `bbPath` and threads1. `bbBinaryPath`/`bbWorkingDirectory` are not PXE options. The SDK's Chonk prover reuses a process-global Barretenberg singleton, so preparation initializes it before account/genesis operations and explicitly checks its stored backend/path/thread options. A preexisting incompatible singleton fails instead of silently ignoring the requested native backend. Native CRS comes from the parent's verified CRS_PATH; parent must deny remote downloads and supervise capacity. The parent owns singleton destruction; wallet.stop runs in finally, and does not claim to own the node's shared global backend.

JSON serialization therefore excludes those objects. Never separately inspect/serialize them or the preparation account. Errors contain only fixed stage and error class; no upstream witness/transaction dump. Later Ready work must recreate/register the same in-memory account and board instance after this wallet is closed, or deliberately revise lifecycle ownership.
